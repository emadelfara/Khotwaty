# خُطوتي (Khotwaty) 👟

**An Arabic-first, offline Flutter pedometer for Android 8.0 (API 26) and newer.**

Khotwaty tracks steps through the phone's hardware step-counter sensor, calculates estimated distance and calories, keeps daily history, and provides an Android home-screen widget.

## Features

- Arabic RTL interface with a dark red-and-black visual identity.
- Hardware step counter and persistent Android foreground service.
- Daily step, distance, and estimated calorie totals.
- Local history for up to 365 days and a weekly comparison chart.
- Milestone notifications at 5,000, 10,000, 15,000 and 20,000 steps.
- Home-screen widget with steps, distance, and calories; tap it to open the app.
- Height and weight settings for better estimates.
- Local-only data; no account, server, ads, or analytics.

## Tech stack

- Flutter / Dart for the app UI.
- Kotlin Android service and platform channel for background sensor tracking.
- Android App Widget (RemoteViews).
- SharedPreferences for native daily records.
- fl_chart for weekly activity visualization.

## Requirements

- Flutter stable
- JDK 17
- Android SDK
- Android 8.0 / API 26 or newer


**macOS / Linux**
```bash
bash tool/bootstrap_android.sh
flutter pub get
flutter run
```

Build a release APK:

```bash
flutter build apk --release
```

GitHub Actions runs dependency resolution, static analysis, widget tests, and a release APK build. The APK is uploaded as the `khotwaty-release-apk` workflow artifact.

## Notes on accuracy and background operation

- Step tracking uses Android's `TYPE_STEP_COUNTER` sensor. Devices without that hardware sensor cannot provide true step counts.
- Android 10+ requires the Activity Recognition permission. Android 13+ also asks for notification permission.
- The foreground service is designed to continue while the app is in the background and after a reboot when tracking was enabled. Battery managers and vendor-specific restrictions can still stop background work; users may need to allow unrestricted battery use.
- Distance is estimated from height-based stride length. Calories are estimates based on distance and entered weight, not medical measurements.
- The step counter reports steps accumulated by the hardware since boot. The app records changes while its tracking service is active.
